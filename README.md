# تمرین‌های پایتون – rezadelkabadi

این مخزن شامل تمرین‌هایی است که در مسیر یادگیری زبان برنامه‌نویسی پایتون حل کرده‌ام. هدف اصلی، تسلط بر مفاهیم پایه و پیشرفته پایتون و آماده‌سازی برای مباحث امنیت و برنامه‌نویسی حرفه‌ای است.

python exercise_2_even_odd.py
